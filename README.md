🌾 Crop Loss Analysis and Prevention System

📌 Project Overview

The Crop Loss Analysis and Prevention System is a data-driven project developed to identify crop loss reasons and provide suitable prevention measures for farmers. The project combines Python, MySQL, and Power BI to manage crop loss information and visualize insights through an interactive dashboard.

🎯 Objectives

- Identify the major reasons for crop losses.
- Store and manage crop loss data using MySQL.
- Develop a Python application to manage project data.
- Visualize crop loss information using Power BI.
- Support better agricultural decision-making through data analysis.

🛠️ Technologies Used

- Python – Application development
- MySQL – Database management
- Power BI – Data visualization and dashboard development

📂 Project Structure

- "Application.py" – Python application
- "Crop_loss_query.sql" – SQL queries
- "Crop_loss_Dashboard.pbix" – Power BI dashboard file
- "crop_loss_dashboard.png" – Dashboard screenshot

📊 Power BI Dashboard

The dashboard provides a visual overview of crop loss information and helps users explore loss reasons and prevention measures.

"Crop Loss Analysis Dashboard" (crop_loss_dashboard.png)

⚙️ How to Use

1. Download or clone this repository.
2. Set up MySQL and create the required database and tables.
3. Execute the SQL queries provided in the SQL file.
4. Configure the database connection in the Python application.
5. Run the Python application.
6. Open the ".pbix" file using Power BI Desktop to explore the dashboard.

💡 Project Outcome

This project combines application development, database management, and data visualization to organize crop loss information and present useful insights for agricultural analysis.
